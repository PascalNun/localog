# LocaLog 0.0.1-alpha

This is the first installable LocaLog build.

It covers the main workflow:

- import an audio or video recording;
- transcribe it locally;
- review and correct the transcript;
- generate a protocol draft with a local language model;
- edit and export the result.

LocaLog does not require an account, cloud workspace, or telemetry. The recording,
transcript, and protocol stay on the Mac during this workflow. Protocol generation
uses Ollama, which must be installed separately and running locally.

## Install

1. Download `LocaLog_0.0.1_aarch64.dmg` below.
2. Open it and drag LocaLog to Applications.
3. Start LocaLog. If macOS warns that it cannot verify the developer, control-click
   the app, choose **Open**, and confirm.

This build is not notarised yet. The warning is about the distribution signature,
not about the application data.

## Before generating a protocol

- Apple Silicon Mac, macOS 13 or later;
- [Ollama](https://ollama.com) installed and running;
- an Ollama model already installed. LocaLog shows the available models in Settings.

Transcription models are downloaded by LocaLog on first use, after showing the size
and asking for confirmation. The transcription, media, and speaker runtimes are
included in this build.

## Current limits

- Review the generated protocol before relying on it. The current quality checks
  cover German meetings; English quality has not yet been measured to the same depth.
- Importing an existing recording is the supported path. Recording inside LocaLog is
  not ready.
- The packaged build currently targets macOS on Apple Silicon. Windows and Linux
  support is planned but not packaged yet.
- Speaker labels are provisional. Rename them in transcript review when you know who
  spoke; automatic identity matching is not enabled.

The project is still under active development. Feedback and reproducible bug reports
are welcome in [GitHub Issues](https://github.com/PascalNun/localog/issues).
